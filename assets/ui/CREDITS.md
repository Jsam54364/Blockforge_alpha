# Menu art credits

`atlas.png` / `atlas.json` are made by `tools/make_ui_atlas.py`. The frames, buttons, gems,
slots, pedestal and logo are painted procedurally by that script and `tools/ui_ornate.py`; the
type comes from these fonts, all under the SIL Open Font License 1.1 (full texts in
`licenses/`), taken from their Fontsource npm packages:

* **Almendra** Bold (the BlockForge logo, drawn into a picture), Ana Sanfelippo
* **Crimson Text** 600 (the menus' text), The Crimson Text Project Authors
* **Pixelify Sans** 500 (the stats overlay), The Pixelify Sans Project Authors
* **Material Icons** (icons), Google (Apache License 2.0 upstream; the Fontsource package's licence file is in `licenses/`)

The look follows concept art the project owner made with ChatGPT.
