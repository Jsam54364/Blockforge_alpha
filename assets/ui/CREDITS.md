# Menu art credits

`atlas.png` / `atlas.json` are made by `tools/make_ui_atlas.py`. The frames, gems and logo
plate are painted by that script; the type comes from these fonts, all under the SIL Open
Font License 1.1 (full texts in `licenses/`), taken from their Fontsource npm packages:

* **Cinzel** 900 (the BlockForge logo), The Cinzel Project Authors
* **Crimson Text** 600 (most menu text), The Crimson Text Project Authors
* **Pixelify Sans** 500 (the main menu's buttons, the keyboard), The Pixelify Sans Project Authors
* **Material Icons** (icons), Google (Apache License 2.0 upstream; the Fontsource package's licence file is in `licenses/`)

The look follows concept art the project owner made with ChatGPT.
